Flaws found

  • Deletion has no guard today. deprecate_removed_urls:71 retires everything not on disk: no cap, no confirmation fetch. A partial crawl can retire pages.
  • Non-200 pages look removed. Ingest skips files whose http_status is not 200 (ingest.py:343), so they never enter active_urls.
  • Nothing in this PR changes ingest. The rules compute departures; the retire path lives in apo-mcp-server.
  • lastmod is trusted. Search engines treat lastmod as a hint when it is consistently accurate. Three hosts have partial lastmod, one has none; 206 URLs are refetched every run. A conditional GET (ETag or Last-Modified) or the existing content hash would catch silent edits; the monthly full run is the only backstop here.
  • The ingest lock is same-machine only. Separate Fargate tasks do not share it, so schedules must not overlap.
  • The reference code is not wired in. No --update flag; per-URL lastmod is not stored in state.db.
