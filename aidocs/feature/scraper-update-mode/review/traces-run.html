Two kinds of sitemap exist. The XML sitemap (/sitemap.xml, 79 of 83 hosts) has dates. The markdown /sitemap-llm (52 Drupal 10 hosts) lists pages and files with no dates, so it cannot say what changed. The snapshot records only "no sitemap", so it cannot tell a host with no sitemap from one that was unreadable (503) on the day; both are handled the same way.

Today, with no update mode, no host depends on a sitemap: the crawl follows links, and sitemap seeding is off in production unless use_sitemap is set (scrape.py passes False by default).
